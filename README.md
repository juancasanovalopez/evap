## Backend

The `backend/` directory contains a serverless Go API (AWS Lambda + API
Gateway HTTP API + DynamoDB) with OAuth2 (Google/GitHub) authentication.
See [backend/README.md](backend/README.md) for local development, and
[infra/](infra) for the Terraform infrastructure.
